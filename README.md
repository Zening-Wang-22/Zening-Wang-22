### 🔬 Research

At **Rice University**, I am co-advised by **[Prof. Marina Vannucci](https://marina.blogs.rice.edu/)** and **[Prof. Cindy Zhang](https://profiles.rice.edu/faculty/cindy-zhang)**. At **Duke University**, I was a teaching assistant for **STA 199: Introduction to Data Science and Statistical Thinking** for **three semesters**. I helped students learn R and RStudio, along with Git and GitHub for version control, collaboration, and reproducible data analysis.
